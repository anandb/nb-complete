Marks a folder as a Markdown project so it opens in the Projects window and its files are browsable as a project.

It is not limited to Markdown files. Any folder with text content — notes, snippets, plain text, documentation — can be used; all files in the folder are shown in the logical view, and folders can be hidden with the project's ignored-files settings.

The folder is marked with a .mdproject file and needs no build system. Existing content is left untouched, so this also works to convert a folder you already use.
