1. Press WIN + R to open the Run dialog box.
2. Enter `cmd` for the Command Prompt.
3. The config directory might not exist, it can be created
<pre><code>
`mkdir "%USERPROFILE%\.config\opencode"
cd "%USERPROFILE%\.config\opencode"`
</code></pre>
4. Start `notepad` and paste in the starter configuration.

> [[Configuration Template->Configuration Template]]

Verify that the configuration is valid by running this from a command prompt
<pre><code>`opencode models`</code></pre>
