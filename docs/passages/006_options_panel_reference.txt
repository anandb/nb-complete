Customise the plugin behavior by navigating to `Tools > Options > Assistant`. Here, you can configure the path to the OpenCode binary, add process arguments, set a global system Preamble for all sessions, and toggle **Local Echo** for instant message rendering. You can also adjust UI preferences like toolbar icon size, chat font size, enable or disable specific features (like Stash Diff or Jump to file), and set a custom user avatar.

Additionally, the plugin includes a background **Update Checker Service** that automatically queries for new releases (with randomised intervals between 16 and 24 hours). You can toggle the update checks under `Tools > Options > Assistant > Check for updates`. When an update is found, you will be prompted with a dialog to download the update immediately, get reminded later, or skip the version entirely.

This page describes every preference in the panel, organised into six sections. All changes take effect when you click **Apply** or **OK**.

##### 3. Chat Behavior

<table class="ug-table">
<thead><tr><th>Preference</th><th>Default</th><th>Description</th></tr></thead>
<tbody>
<tr><td><strong>Echo user input immediately (Local Echo)</strong></td><td>On</td><td>Renders your message instantly in the chat while the server is processing, instead of waiting for the first response.</td></tr>
<tr><td><strong>Session Idle Timeout (seconds)</strong></td><td>600</td><td>How long (0–3600, step 5) a request may sit idle — with no data arriving from the server — before it is failed. This is an <em>idle</em> timeout, not an absolute deadline, so long-running responses that keep streaming are never cut off.</td></tr>
<tr><td><strong>Combine tool and thought bubbles into a single accordion</strong></td><td>On</td><td>Groups tool outputs and reasoning into one expandable header instead of separate bubbles. Changing this reloads the current session.</td></tr>
<tr><td><strong>Prompt to initialize global opencode config</strong></td><td>On</td><td>When no global opencode configuration exists, the chat panel offers to create a starter configuration (Yes / Not now / Don't ask again).</td></tr>
<tr><td><strong>Auto-backup uncommitted changes on turn start (git/hg) (Experimental)</strong></td><td>On</td><td>Stashes uncommitted changes in git/hg repositories before each turn, so the AI can be rolled back safely.</td></tr>
<tr><td><strong>Max Messages</strong></td><td>100</td><td>The maximum number of visible bubbles (10–200, step 5) kept in the chat panel before older ones are trimmed from the view to conserve memory. The full history remains on the server and can be reloaded.</td></tr>
</tbody>
</table>

<table class="ug-table">
<thead><tr><th>Preference</th><th>Default</th><th>Description</th></tr></thead>
<tbody>
<tr><td><strong>Enable context menu additions (Sort, Minify, Search Web)</strong></td><td>On</td><td>Adds the <strong>Sort Lines</strong>, <strong>Minify JSON</strong>, and <strong>Search Web</strong> items to the editor's right-click context menu.</td></tr>
<tr><td><strong>Enable Stash Diff toolbar button and action</strong></td><td>On</td><td>Enables the <strong>Stash Diff</strong> toolbar button and the <code>Ctrl + Shift + L</code> action for viewing git stash diffs.</td></tr>
