### About

<a href="https://geminicli.com" target="_blank" rel="noopener">Gemini CLI</a> is an AI agent command-line tool. It natively supports communication with external tools using the <a href="https://agentclientprotocol.com" target="_blank" rel="noopener">Agent Client Protocol</a>.

The executable you configure in BeanBot is <code>gemini</code>, run with the default launch argument <code>--acp --model gemini-3.5-flash</code>.

Gemini Agent in BeanBot supports:
- **Editor Context**: Seamlessly injects the active editor state into agent prompts.
- **MCP Servers**: Automatically registers and injects the plug-in's [[MCP Tools]].
- **Client-Side Session Tracking**: Since Gemini CLI does not natively maintain session lists, BeanBot manages session state locally on the client.

### Model Selection

Since Gemini CLI does not support changing the model dynamically via <code>session/set_config_option</code> once the session has started, you can configure your preferred model in one of three ways:

1. **Launch Arguments**: In the plugin options (<code>Tools > Options > Assistant > System</code>), append your desired model to the arguments, e.g., <code>--acp --model gemini-2.5-pro</code>.
2. **Settings File**: Define the default model in your global configuration file at <code>~/.gemini/settings.json</code>.
3. **Environment Variable**: Set the <code>GEMINI_MODEL</code> environment variable before launching NetBeans.
