![Jump to File dialog for searching files across open projects](../images/ide_enhancements-1.png){style="max-width:100%;"}

The **Jump to File** dialog (`Ctrl + Alt + J`, or `Cmd + Option + J` on Mac) lets you open any file across all open projects by typing part of its name. It matches case-insensitively by filename prefix, path substring, or glob patterns. Navigate with the arrow keys and press `Enter` to open.

The dialog is backed by an in-memory index that rebuilds in the background and updates live as files change; it respects `.gitignore` and skips common directories like `node_modules/`, `target/`, and `build/`. Enable or disable it under `Options > Assistant`.
