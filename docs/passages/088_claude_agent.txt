<div style="font-weight: bold; margin-top: 0.8em; margin-bottom: 0.2em;">Install</div>

All platforms (requires Node.js 18+):

<pre><code>`npm install -g @agentclientprotocol/claude-agent-acp`</code></pre>

The package bundles the Claude Agent SDK, so a separate `claude` CLI install is not needed.

<div style="font-weight: bold; margin-top: 0.8em; margin-bottom: 0.2em;">About</div>

<a href="https://github.com/agentclientprotocol/claude-agent-acp" target="_blank" rel="noopener">Claude Agent ACP</a> is an ACP adapter that exposes Claude's coding agent over the <a href="https://agentclientprotocol.com" target="_blank" rel="noopener">Agent Client Protocol</a>, which is what BeanBot speaks. It supports session mode switching, MCP server injection, and editor context.

The executable you configure in BeanBot is <code>claude-agent-acp</code>.
