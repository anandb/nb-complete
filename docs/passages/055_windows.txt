On Windows, it is better to run OpenCode inside **WSL (Windows Subsystem for Linux)** for the best performance and compatibility. This allows it to execute regular bash commands. You can also use a package manager like chocolatey or scoop if you have them.

##### Using the install script from WSL
<pre><code>`curl -fsSL https://opencode.ai/install | bash`</code></pre>

##### Chocolatey
<pre><code>`choco install opencode`</code></pre>

##### Scoop
<pre><code>`scoop install opencode`</code></pre>
