If the plugin can't find the `opencode` binary, the chat panel shows an install-help bubble instead of the normal input:

*   A copyable, OS-specific install command (e.g. `curl -fsSL https://opencode.ai/install | bash`)
*   A **View OpenCode Setup Guide** link
*   A **Restart ACP Server** button (the toolbar restart button pulses to draw attention)

After installing OpenCode — and optionally setting the binary path under `Options > Assistant` — click **Restart ACP Server** to connect.
