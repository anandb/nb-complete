[Ollama](https://ollama.com) lets you run open-source models locally on your own machine. The first step is installing it.

Download the installer for your operating system from the [Ollama website](https://ollama.com/download) and run it. On Linux you can also use the install script:

<pre><code>
curl -fsSL https://ollama.com/install.sh | sh
</code></pre>

On macOS, Ollama installs as a regular app — launch it once so the background service starts. **Windows (10 or later)** is also supported: install via the standalone `OllamaSetup.exe` download, or run the PowerShell installer:

<pre><code>
irm https://ollama.com/install.ps1 | iex
</code></pre>

Verify the installation by opening a terminal (or PowerShell on Windows) and running:

<pre><code>
ollama --version
</code></pre>

Once the `ollama` command responds, move on to fetching a coding model.
