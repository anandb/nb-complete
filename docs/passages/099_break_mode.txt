The header button to the left of the mini-assistant icon latches two states. Released, it shows a padlock and permission requests behave as described above. Pressed, it shows a coffee cup: you are on a break, and the plugin answers every permission request with **Allow Once** on its own — no prompt, no diff preview, nothing moves focus — until you press the button again. Arming it asks for confirmation once, because from that point on tool calls proceed without review. Releasing it never asks.

Arming also gives the coffee icon one short two-beat pulse (about a second) so the change of state is caught even in peripheral vision; after that the icon stays still. The latched button, its tooltip and the auto-allowed result lines in the chat carry the state — there is no repeating blink.

The mode lasts only for the current IDE session; it is never stored, so a restart returns to normal prompting.
