Navigate and control the assistant efficiently using keyboard shortcuts:

<table class="ug-table">
<thead><tr><th>Shortcut</th><th>Action</th></tr></thead>
<tbody>
<tr><td><code>Ctrl + L</code></td><td>Toggle the assistant panel (open or close)</td></tr>
<tr><td><code>Alt + Up</code> / <code>Alt + Down</code></td><td>Cycle through previously sent messages</td></tr>
<tr><td><code>Page Up</code> / <code>Page Down</code></td><td>Scroll the chat</td></tr>
<tr><td><code>Ctrl + R</code></td><td>Search message history</td></tr>
<tr><td><code>Ctrl + Alt + J</code> (or <code>Cmd + Option + J</code> on Mac)</td><td>Open the Jump to File dialog</td></tr>
<tr><td><code>Ctrl + Shift + L</code></td><td>Open the Stash Diff viewer</td></tr>
<tr><td><code>/</code></td><td>Open the slash command autocomplete popup</td></tr>
<tr><td><code>Tab</code></td><td>Accept the highlighted autocomplete command and insert it into the input area</td></tr>
<tr><td><code>Escape</code></td><td>Close the options panel</td></tr>
</tbody>
</table>
