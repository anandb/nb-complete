Typing `/` in the input area opens an autocomplete popup listing all available commands — the plugin's local commands plus the server commands advertised by the OpenCode agent. Keep typing to narrow the list. Use Up/Down to highlight an entry, then press `Enter` or `Tab` to insert the highlighted command into the input. If the typed text exactly matches a command name, pressing `Enter` sends it immediately. The popup disappears when you press `Escape`, type a space, or click away.

See [[Commands]] for the full list of available commands and what each one does.
