Before each turn, the plugin can back up your uncommitted changes by stashing a copy (`git stash`, or `hg shelve`) so work can be retrieved safely if the AI makes unwanted modifications. The backup appears as an **Auto-Backup** tool bubble in the chat. This is enabled by default under `Options > Assistant > Chat Behavior > Auto-backup uncommitted changes on turn start (git/hg)` and can be disabled there.

If you see too many stashes piling up, you can ask the plugin to cleanup by sending a message like "Drop all stashes starting with the name beanbot except for the most recent 5"
