Before each turn, the plugin can back up your uncommitted changes by stashing them (git stash, or hg shelve for Mercurial) so work can be rolled back safely if the AI makes unwanted modifications. The backup appears as an **Auto-Backup** tool bubble in the chat. This is enabled by default under `Options > Assistant > Chat Behavior > Auto-backup uncommitted changes on turn start (git/hg) (Experimental)` and can be disabled there.
