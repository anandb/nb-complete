The plugin runs a small built-in MCP (Model Context Protocol) server inside the IDE and exposes it to the OpenCode agent server. When the agent supports MCP, it can call a handful of NetBeans tools directly during your conversation — you don't have to switch to the IDE and click around:

<thead><tr><th>Tool</th><th>What it does</th></tr></thead>
<tbody>
<tr><td><code>get&#95;tabs</code></td><td>Lists the file paths currently open in editor tabs (only files inside your open projects).</td></tr>
<tr><td><code>open&#95;pos</code></td><td>Opens a file at a given line number in the editor and focuses it. Useful when the AI says "Show me where this happens in the code".</td></tr>
<tr><td><code>list&#95;projects</code></td><td>Lists the absolute paths of all open NetBeans projects.</td></tr>
<tr><td><code>rename&#95;session</code></td><td>Gives the current (or a specific) session a custom title, just like the rename button.</td></tr>
<tr><td><code>add&#95;task</code></td><td>Creates a task in a BeanBot Tasks repository. Accepts summary, status, priority (A–Z), tags, projects, due date, estimate, and consumed. See [[Adding Tasks via AI]].</td></tr>
<tr><td><code>diff&#95;stash</code></td><td>Opens the side-by-side stash diff viewer for a given stash. Only available when Stash Diff is enabled in Options.</td></tr>
<tr><td><code>read&#95;file</code> / <code>write&#95;to&#95;file</code></td><td>Reads or writes a file inside one of your open projects. <code>write&#95;to&#95;file</code> can create missing parent directories.</td></tr>

<tr><td><code>git&#95;status</code> / <code>git&#95;diff</code></td><td>Runs git status (short form) or git diff (unstaged, staged, or a specific revision) for a repository inside an open project.</td></tr>

All filesystem and git tools are confined to your currently open projects — paths outside them (including symlinks that point outside) are rejected. The MCP server binds to <code>127.0.0.1</code> and verifies a per-instance token, so it never accepts connections from outside your machine; agents that cannot carry tokens (the PI harness) connect without one. The server port can be fixed in Options (Assistant > System); by default the OS picks a random free port. It only activates when your agent server advertises MCP support. When the AI uses one of these tools, the call and its result appear in the chat as a collapsible tool bubble with the tag icon — same as any other tool output.
