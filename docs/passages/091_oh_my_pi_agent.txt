### About

**Oh My Pi (omp)** is an open-source, terminal-based AI coding agent forked from the Pi agent, designed to be a "batteries-included" version integrating full IDE-like capabilities into a terminal harness.

The executable you configure in BeanBot is <code>omp</code>, run with the default launch argument <code>acp</code>. 

Oh My Pi Agent in BeanBot supports:
- **Editor Context**: Seamlessly injects the active editor state into agent prompts.
- **MCP Servers**: Automatically registers and injects the plug-in's [[MCP Tools]].
- **Message Queueing**: Queues and batches user prompts at turn end.
- **Session Management**: Supports full session lists and state persistence.
