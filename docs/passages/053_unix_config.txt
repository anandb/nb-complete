On macOS/Linux, the OpenCode configuration is located at `$HOME/.config/opencode/opencode.json`.

1. Create this directory if it doesn't exist
<pre><code>`mkdir -p $HOME/.config/opencode.`</code></pre>

2. Start your editor, whether it be `vi`, `nano` or any other.
3. Create the file `$HOME/.config/opencode/opencode.json` with the following template.

> [[Configuration Template->Configuration Template]]

Verify that the configuration is valid by running
<pre><code>`opencode models`</code></pre>

> [[After Installing OpenCode->Post Install]]
