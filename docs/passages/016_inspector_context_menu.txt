After running inspections (e.g. via `Analyze > Inspect & Transform`), right-click any item in the **Inspector** window to see two actions:

*   **Copy** — copies the selected subtree (filename, line number and description of each problem) to the clipboard as text.
*   **💬 Send to Assistant** — pre-fills the Mini Assistant input with the same text, so you can edit it before sending.

The same **Copy** / **💬 Send to Assistant** actions are also available in the **Test Results** window on failed tests.
