- **macOS / Linux** (Recommended):

- **NPM (Global):**
  <pre><code>`npm install -g opencode-ai`</code></pre>
- **Homebrew (macOS):**
  <pre><code>`brew install anomalyco/tap/opencode`</code></pre>
