#### Install

- **macOS / Linux / WSL (npm)**: `npm install -g @qwen-code/qwen-code`
- **Windows (npm)**: `npm install -g @qwen-code/qwen-code`

The npm route requires **Node.js 20 or newer**. CLI docs: <a href="https://qwenlm.github.io/qwen-code-docs/" target="_blank" rel="noopener">qwenlm.github.io/qwen-code-docs</a>.

#### About

<a href="https://qwenlm.github.io/qwen-code-docs/" target="_blank" rel="noopener">Qwen Code</a> is an AI coding agent command-line tool. Running <code>qwen --acp</code> makes it act as an **ACP server** over stdio: it speaks JSON-RPC on stdin/stdout and is meant to be spawned by an ACP-aware editor, so it is not a command to run yourself.

The executable you configure in BeanBot is <code>qwen</code>, run with the default launch argument <code>--acp</code>.

**Authentication** is a CLI prerequisite: set <code>OPENAI&#95;API&#95;KEY</code> or <code>DASHSCOPE&#95;API&#95;KEY</code> before the first session. BeanBot has no in-chat sign-in for Qwen Code, so a fresh install without credentials fails <code>session/new</code> — export the key first, then pick Qwen Code in the chooser.

Qwen Code in BeanBot supports:
- [[Editor Context->Automatic Context Capture]] Seamlessly injects the active editor state into agent prompts.
- **[[MCP Tools]]**: Qwen Code accepts a per-session MCP server, so BeanBot hands it the plugin's internal server automatically — no manual registration is needed.
- **Model Selection**: Exposed as an ACP config option, so the in-session model dropdown works.
- **Agent / Mode List**: The agent selector is offered, and mode changes go through the protocol's mode request, so the dropdown works in an open session.
- **Session List**: Sessions come from Qwen Code itself, so the dropdown reflects its own list and needs no local tracking.
- **Session reload**: Qwen Code implements <code>session/load</code>, so [[Reloading a Session]] works for sessions it has already persisted.
- **Queued messages**: a message sent while a turn is running is held in the [[Queuing Messages]] toolbar queue until the turn ends. Qwen Code accepts a second prompt but that supersedes the running turn (the first execution is cancelled with an internal error), so sending immediately would cut the turn short.

#### Limitations

- **No session close or delete**: Qwen Code advertises neither <code>session/close</code> nor <code>session/delete</code>, so the dropdown has no **Delete Session…** item and a session stays in the list after you leave it. [[Archiving Sessions]] is local only.
- **Model switching path**: BeanBot changes the model through Qwen Code's <code>model</code> config option and mode request, not the dedicated model request. The dropdown shows the options Qwen Code reports back, not a fixed list.
- **Queued messages**: a second prompt mid-turn supersedes the running turn, so BeanBot holds the message until turn end (see [[Queuing Messages]]). Interleaved agents such as [[OpenCode]] send immediately instead.
