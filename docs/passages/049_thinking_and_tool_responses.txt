Advanced models use a "thinking" budget to reason before responding. This internal reasoning is displayed in its own collapsible pane. Similarly, when the AI uses tools, the tool output is shown in collapsible panes marked with a tag icon. You can use the **Filter** button to hide these thought or tool bubbles from the chat view, or use the **Expand/Collapse All** button to manage them all at once. By default, consecutive tool and thought bubbles are combined into a single expandable accordion, so you can collapse them together. You can turn this off under `Options > Assistant > Combine tool and thought bubbles into a single accordion`. Error messages will appear as red-tinted bubbles, and tables are rendered cleanly with alternating row colours.
