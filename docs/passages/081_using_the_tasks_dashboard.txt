Once a repository is registered, your tasks appear in the NetBeans <b>Tasks Dashboard</b> (Window &gt; Tasks). You can:

<ul>
<li><b>Create tasks</b> via the dashboard's "New Task" button or from the assistant's toolbar.</li>
<li><b>Edit tasks</b> by double-clicking them — the task editor opens with Summary, Status, Priority, Tags, Projects, Estimate, and Consumed fields. See [[Task Editor]].</li>
<li><b>Set due dates</b> via the dashboard's Schedule submenu (right-click a task &gt; Schedule).</li>
<li><b>Filter by tags</b> using the Find Tasks query dialog.</li>
</ul>

The dashboard's Open / Finished grouping follows the task status: tasks marked closed (the todo.txt <code>x </code> prefix) appear under Finished; everything else is Open.

Tasks can also be created conversationally via the AI — see [[Adding Tasks via AI]].
