On agents that drop an in-flight prompt if you send another (see below), you don't have to wait for the assistant to finish before typing. While the agent is working (Go/Stop button shows the running state), anything you send is <b>queued</b> instead of interrupting the current turn.

When the turn ends, all queued messages are combined into a single prompt and sent automatically. The queue button appears on the toolbar with a small wobble animation while messages are waiting:

<ul>
<li><b>Send Now</b> — open the queue button's popup menu to flush the queued messages immediately, without waiting for the turn to end.</li>
<li><b>Cancel Queue</b> — discard all queued messages.</li>
</ul>

Queueing is used when a second <code>session/prompt</code> would drop the in-flight turn. That is currently [[Goose Agent]], [[PI Agent]], [[Hermes Agent]], and [[Oh My Pi Agent]]. Interleaved agents ([[OpenCode]], [[Cursor Agent]], [[Claude Agent]], [[Gemini Agent]]) send immediately instead. If you close or switch sessions before the turn ends, pending messages are cancelled with the rest of the panel state.
