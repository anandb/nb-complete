  <div style="font-weight: bold; text-align: left; flex-grow: 1;">Queuing Messages</div>
  <div>[[Index->Topic Index]]</div>
</div>

On agents that drop an in-flight prompt if you send another (see below), you don't have to wait for the assistant to finish before typing. While the agent is working (Go/Stop button shows the running state), anything you send is <b>queued</b> instead of interrupting the current turn.

When the turn ends, all queued messages are combined into a single prompt and sent automatically. No chat bubbles appear while messages are queued — a single bubble for the combined text is drawn when it is actually sent. The queue button appears on the toolbar with a brief amber flash on the first message, then wobbles periodically while more messages accumulate:

<ul>
<li><b>Send Now</b> — open the queue button's popup menu to flush the queued messages immediately, without waiting for the turn to end.</li>
<li><b>Cancel Queue</b> — discard all queued messages.</li>
</ul>

Queueing is used when BeanBot must not send a second <code>session/prompt</code> into the running turn: [[PI Agent]] (with its default adapter), [[OpenClaw Agent]], [[Codex Agent]], [[Kilo Code Agent]], [[Cline Agent]] and [[Jcode Agent]]. [[Goose Agent]] and [[Hermes Agent]] queue as a fallback when their steer route cannot be used (no active run, or attachments on Hermes' text-only steer). Interleaved agents ([[OpenCode]], [[Cursor Agent]], [[Copilot Agent]], [[Gemini Agent]], [[Devin Agent]]) send immediately instead. If you close or switch sessions before the turn ends, pending messages are cancelled with the rest of the panel state.

An agent can also take your message <b>inside</b> the running turn instead of queueing or starting a new one. [[Goose Agent]] injects through its own steering extension and [[Hermes Agent]] posts it as <code>/steer</code>; both draw your bubble immediately. When an agent advertises the cross-adapter <code>&#95;session/steering</code> extension, BeanBot injects the text and attachments at the agent's next step boundary, so the agent adapts mid-turn: [[Claude Agent]] and [[Oh My Pi Agent]] always have it, and [[PI Agent]] has it when you install a steering-capable adapter (<code>@automatalabs/pi-acp</code>, <code>@openma/pi-acp</code> or <code>@gugu-acp/pi-acp</code>) — the default <code>@geohar/pi-acp</code> queues instead. If the turn ends just before the injection lands, the text and attachments go back into the composer.
