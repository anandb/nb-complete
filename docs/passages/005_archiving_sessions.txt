![Archiving a session from the session dropdown context menu](../images/archiving_sessions-1.png){style="max-width:100%;"}

Keep your active session list clean by archiving old conversations instead of deleting them. You can archive a session by right-clicking on the session dropdown (not expanding it) and then selecting Archive. This hides it from the session dropdown. You can toggle the visibility of archived sessions by clicking the eye icon on the toolbar to the left of the dropdown. There is also a toolbar button to archive the session, you can use either option.

The session context menu also provides **Archive All** and **Archive Others**. Archive All hides every listed session; Archive Others hides every listed session except the currently selected one. If Archive All leaves no visible sessions, the mini assistant closes; Archive Others keeps the selected session available.

Archiving is a BeanBot feature, not the Harness. For agents that publish a session list, BeanBot filters archived rows after fetching them from the server — the conversation is still on the server. For [[Gemini Agent]], sessions are tracked only on this machine: archive hides them in the dropdown; there is no remote list to keep them on.
