After running a test suite, right-click any failed test (or failure tree) in the **Test Results** window to access two actions:

*   **Copy** — copies the selected failure subtree (test name, file, line and failure message) to the clipboard as text.
*   **💬 Send to Assistant** — pre-fills the Mini Assistant input with the same text so you can ask for a diagnosis or fix.

These actions share the same popup helper (`TreePopupSupport`) as the Inspector window.
