With Ollama installed, open a terminal and pull a model suited for code. Good options include:

<pre><code>
ollama pull deepseek-coder
ollama pull qwen2.5-coder
ollama pull codellama
ollama pull llama3.1
</code></pre>

The first run of `ollama run <model>` will download the model if it is not already present. You can see what is installed at any time with:

<pre><code>
ollama list
</code></pre>

Remember the exact model names shown by `ollama list` — you will need them when [[configuring OpenCode->Configure OpenCode for Ollama]].
