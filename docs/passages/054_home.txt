BeanBot is a NetBeans plugin that provides an AI assistant panel powered by the [Agent Client Protocol](https://agentclientprotocol.com). It lets you chat with AI models directly inside the IDE, automatically attaching active project and source file context to your messages. It also features a built-in permission handler — allowing you to inspect code diffs before applying changes and explicitly approve file deletions or terminal commands.
