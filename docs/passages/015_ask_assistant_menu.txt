Two editor menu entries launch the Mini Assistant for refactoring help:

*   Right-click in the editor and choose **Refactoring > Ask Assistant...** to send the current selection to the assistant for refactoring.
*   Use the code generator — press `Alt + Insert` (or open the Insert Code menu) and pick **Ask Assistant** to generate code from a prompt.

Both open (or focus) the Mini Assistant with your selected code attached as context.
